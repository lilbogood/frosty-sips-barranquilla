"Método de pago: contra entrega."

El cliente añade productos.

Revisa el carrito.

Completa los datos necesarios.

Selecciona domicilio o recogida, cuando estén habilitados.

El cliente pulsa enviar.

FROSTY LAB confirma el pedido por su canal comercial.

El pago contra entrega no significa que el pago se haya realizado en el momento de generar el mensaje.
